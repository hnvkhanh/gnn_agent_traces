# Continual learning on unsure decisions: agentdojo, split=task

Unsure = confidence after temperature scaling < **0.90**; a trace is queried (labels revealed, model trained on it) if any of its actions is unsure. 3 round(s), seeds [0, 1, 2], update 10 epochs at lr 0.0003, strategies finetune, replay, ergnn, agem, twp, buffer 50. Values are means over seeds (and over A->B / B->A for held-out); `before -> after` compares with the same base model without any update on the same traces.

**Read this first.** `full` / `all` scores traces that were trained on when queried, so it is optimistic. The leakage-free number is `heldout` (query fold A, score fold B with disjoint task groups). `nonqueried` shows what happened to the traces that were never queried.
